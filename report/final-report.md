# 个人网站最终报告

## 1. 网站定位

本网站面向同学、教师、项目合作伙伴和实习 HR，公开定位为“金融科技与区块链方向本科生，关注金融数据分析、业务原型开发与 AI 辅助项目实践”。页面以单页形式呈现 Hero、About、Skills、Projects、Contact 五个核心区块，重点说明学习方向、能力结构、一个可验证的课程项目和联系入口。

公开地址：<https://824man824-bit.github.io/personal-resume/>

## 2. 模板选择

项目保留仓库既有的 Jekyll 与 `modern-resume-theme` 技术栈。选择继续使用该模板的原因是：它与 GitHub Pages 兼容，已有清晰的配置、布局、包含文件与 Sass 职责划分，适合在不引入额外前端框架的情况下完成单页个人站点。

实施中没有替换技术栈，而是在 `_config.yml`、现有布局和局部样式上完成内容、语义、响应式和可访问性调整，并保留原模板名称、仓库链接与 MIT License。

## 3. AI 参与

AI 参与了需求整理、PRD 与设计文档起草、配置与模板修改建议、样式调试、隐私与占位词扫描、GitHub Pages 故障排查、浏览器自动化验收和报告整理。

AI 没有自行补写个人经历、技能等级、项目结论或公开链接。个人信息以用户确认内容为准，项目事实以用户授权的最终课程论文口径为准；统计相关、显著性和因果边界均保留人工确认后的谨慎表述。头像只做确定性裁剪、居中和 WebP 压缩，没有生成式重绘或外貌修改。

最终桌面与手机截图采用用户提供的原始视口截图，只进行确定性裁切、缩放、标注和拼接；没有使用生成式图像修改页面内容。

## 4. 个人判断

- 只展示一个证据最完整的低空经济政策分析项目，不用模板项目凑数量。
- 将项目内容按研究问题、主要工作、工具、结果与表述边界组织，避免把不显著结果写成“没有作用”，也不把统计关系写成确定因果。
- 只公开称呼、已确认简介、GitHub、邮箱和授权头像，不公开电话、出生日期、性别、政治面貌、本地路径或凭据。
- 使用中性浅色与深色模式、系统无衬线字体、受控内容宽度和清晰焦点轮廓，避免复杂动画与装饰噪声。
- 在用户反馈后优先修复影响理解和可信度的问题：异常高亮、头像中轴、标题层级和窄屏溢出。
